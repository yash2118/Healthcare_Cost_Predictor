# Healthcare_Cost_Predictor

### This project is an AI-powered Healthcare Cost Prediction Tool designed to estimate individual healthcare expenses with 88% accuracy, classify patients into risk tiers (Low, Medium, High), and recommend proactive care strategies. The tool also includes a smoking cessation impact analysis and a premium optimization module to assist insurance companies in pricing and portfolio management.

## Tech Stack
## Programming Language: Python

## Framework: Streamlit

## Libraries: Scikit-learn, SHAP (Explainable AI), Pandas, Matplotlib, Joblib

### This tool leverages machine learning and explainable AI to provide transparent predictions and actionable insights for insurers and healthcare providers.
